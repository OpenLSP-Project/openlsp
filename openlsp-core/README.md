# OpenLSP Core

## Overview

OpenLSP Core is the future reference implementation foundation for the Open Language Service Protocol.

This directory will contain reusable components required for OpenLSP implementations.

---

## Purpose

OpenLSP Core aims to provide:

- Message handling
- Session management
- Protocol utilities
- Validation tools

---

## Development Status

Current status:

Early development stage.

The first versions will focus on:

- Message creation
- Message parsing
- Session lifecycle experiments
